# 参考手册（Reference）

按功能模块组织的全部函数与命令。每个函数均提供说明与简单使用示例。

> **注意：** 标注为「内部函数」的函数未在 NAMESPACE 中导出，需通过 `Rclade:::function_name()` 三冒号语法访问。


| 模块 | 说明 |
|------|------|
| [核心可视化](core-visualization.md) | 用于绘制、保存与汇总系统发育时间树的主函数。 |
| [树与序列读取及校验](tree-sequence.md) | 读取树文件、校验序列文件，并检验单系性。 |
| [分类学解析](taxonomy-parsing.md) | 检测标签格式、解析分类学标签、将分组解析为最近共同祖先（MRCA），并校验自定义分组。 |
| [颜色与图例](colors-legend.md) | 生成色盲友好的调色板，并拆分图例以生成出版级图表。 |
| [命令行与交互界面](cli-interactive.md) | 通过命令行运行 Rclade、启动 Shiny 应用、运行自检，并支持可中断的批量处理。 |
| [日志与计时](logging-timing.md) | 提供结构化、分级的日志与计时功能，便于追踪流程运行状态。 |
| [工具函数](utilities.md) | 跨平台路径拼接、编码检测、临时文件管理及其他辅助函数。 |
