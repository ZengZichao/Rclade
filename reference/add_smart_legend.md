# Add smart legend to a tree plot

Add smart legend to a tree plot

## Usage

``` r
add_smart_legend(p, colors, rank_name, position, nrow, ncol)
```

## Arguments

- p:

  ggplot object

- colors:

  Named color vector

- rank_name:

  Display name for the rank

- position:

  Position: cardinal direction or length-2 numeric vector

- nrow:

  User-specified rows

- ncol:

  User-specified columns

## Value

ggplot object
