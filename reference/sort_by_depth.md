# Sort groups by MRCA node depth (deepest first)

Sort groups by MRCA node depth (deepest first)

## Usage

``` r
sort_by_depth(groups, mrca_map, tree)
```

## Arguments

- groups:

  Character vector of group names

- mrca_map:

  Output of compute_mrca_map()

- tree:

  phylo object

## Value

Sorted character vector
